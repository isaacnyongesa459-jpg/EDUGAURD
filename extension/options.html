Enrollment connects this Chrome/Edge profile to the school policy service.

What this extension does

When installed and granted access, EduGuard applies approved-site policy and reports website navigation domains and timestamps, allowed/blocked outcomes, and time on a site where it can be reliably measured. Full-URL capture is disabled; only domain-level labels are sent. Application names are not collected by this browser extension.

It does not collect credentials, keystrokes, private messages, personal files, microphone or webcam data. It does not control other apps, other browsers, your operating system, or network devices. This extension can be removed unless separately managed by school controls.

Browser host access (<all_urls>) is high-impact: it allows the extension to apply navigation rules across websites. It is used for school policy enforcement and only to report the activity described above, not to scrape page content.

HTTPS is required, except for localhost development.
